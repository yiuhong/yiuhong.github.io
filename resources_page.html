Useful Resources

A curated collection of resources for students, researchers, and enthusiasts in cognitive neuroscience, psychology, and data analysis. Here you will find recommended readings, foundational literature, methodological tutorials, and open-source tools.

Books

Essential readings covering cognitive neuroscience, EEG methodology, and psychological research.

Title Author(s) Description Link
Analyzing Neural Time Series Data Mike X Cohen A comprehensive guide to analyzing EEG and related time series data. An absolute must-read for anyone starting out with electrophysiology. Link
Cognitive Neuroscience: The Biology of the Mind Michael S. Gazzaniga, Richard B. Ivry, George R. Mangun The gold standard textbook providing an extensive overview of how the brain enables the mind. Link

Seminal Journal Articles

Key papers covering metacognition, decision-making, and neuroimaging.

Title / Topic Citation Description Link
Metacognition and Confidence Fleming, S. M., et al. (2010). Science, 329(5998), 1541-1543. This paper highlights the structural neural correlates in the anterior prefrontal cortex associated with inter-individual differences in metacognitive ability. Link
Perceptual Decision Making Gold, J. I., & Shadlen, M. N. (2007). Annual review of neuroscience, 30, 535-574. A foundational review of how sensory evidence is accumulated to make simple perceptual decisions, largely focusing on non-human primate research. Link

Tutorials & Guides

Step-by-step guides for experimental design, behavioral tasks, and data analysis.

Resource Name Type / Platform Description Link
PsychoPy Builder Software Tutorial Learn how to create robust behavioral and neuroimaging paradigms using the open-source PsychoPy application. Perfect for timing-critical tasks. Link
Jamovi for Beginners Software Tutorial A modern, free, and open-source alternative to SPSS. These tutorials cover basic data wrangling, descriptive statistics, and common inferential tests. Link
MNE-Python EEG Analysis Coding Guide (Python) An introduction to analyzing human neurophysiological data with Python. Covers preprocessing, ERPs, and time-frequency analysis. Link

Useful GitHub Pages & Repositories

A collection of open-source tools and community-driven projects relevant to our field.

Repository Name Focus Area Description Link
MNE-Python Neurophysiology Data Open-source Python package for exploring, visualizing, and analyzing human neurophysiological data. Link
PsychoPy Experimental Design Application for the creation of experiments in behavioral science (Python). Link
EEGLAB EEG Data Analysis An interactive Matlab toolbox for processing continuous and event-related EEG, MEG and other electrophysiological data. Link
Brainstorm Brain Recording Analysis Collaborative, open-source application dedicated to the analysis of brain recordings: MEG, EEG, fNIRS, ECoG, depth electrodes and multiunit electrophysiology. Link
